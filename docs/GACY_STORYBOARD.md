# Gacy storyboard

Shot list for `GacyDocumentary`, cut to `ElevenLabs_John_Wayne_Gacy_מאחורי_הסיוט.mp3` (645.30 s).

Times are seconds into that file. Each row is one shot in `SHOTS` (`src/gacy/data/timeline.ts`), and the shot's component is in `src/gacy/shots/`. "In" is how the shot starts: a cut, a dissolve (**diss**), a fade up from black (**black**), or an object crossing the lens (the wipe kind). Every cut sits in a pause of the voice.

Only the labels listed under **Labels** are on-screen type. Everything else that can be read is part of the picture: a shop sign, a folder tab, a stamp, a name typed on a file.
